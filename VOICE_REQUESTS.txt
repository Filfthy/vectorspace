VOICE LINES WANTED
==================

New lines for content added since v400, in the style guide format.
Same voice as the existing mission callouts. Save each mp3 into voices/
under the exact filename shown and it plays in game automatically; no code
change needed (the game checks for the file at start-up). Lines without a
recording keep using the on-screen text and the older generic callouts.
Already-recorded lines are reused where they fit (the pirate ambush uses
pirateambushdestroythepirates.mp3).

The list comes from voice-requests.js. Edit the text there and the filename
changes with it.
