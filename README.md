# Vector Space — Agent X

A vector-graphics space combat game. This repo is a fresh start; the previous
version lives in [vectorspace-archive](https://github.com/Filfthy/vectorspace-archive).

- `docs/` — design direction, world lore, mission and model style guides
- `music/` — calm and violent tracks, with credits
- `voices/` — processed voice lines (`normalize.bat` builds them from `voices unprocessed/`)
- `reference/` — vector font, line models and network logos from the previous version, to port across
